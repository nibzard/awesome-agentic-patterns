# Pattern catalogue audit — October 2026

Full review of all 203 patterns in `patterns/`, run on 2026-10-12 and 2026-10-13.

## Method

1. Indexed every pattern (front-matter, sections, sources, dates).
2. Fanned out 44 review agents, one per category-grouped batch of about 5 patterns.
3. Each agent read every pattern file in its batch, fetched the primary source, ran 2-4 web searches per pattern, and checked the catalogue for duplicates.
4. An adversarial verifier re-checked every proposed decommission. It kept 3 of 5 and downgraded 2.

Totals: 49 agents, 1,321 tool calls, 0 failures. Every pattern received a source check and at least one web search.

## Decommission (3, verified)

These three survived adversarial review. Remove or merge them.

1. **`coding-agent-ci-feedback-loop.md`** — Admits in its own References that it derives from `background-agent-ci.md` and repeats the same branch-push, CI-poll, patch, notify loop, diagram, and retry budget. The cited video (Will Brown, "Open Questions in Agentic RL") covers async RL pipelines and never describes CI loops, so the primary source is miscited. The cited Anthropic page covers worktrees, plan mode, and @-references; it never describes "agentic search over vector embeddings" or the claimed thresholds, so the attribution is fabricated. The surviving artifact on docs.rs is an SEO backlink tool that documents none of the claimed value-ping, RTC-token, UDP, or blockchain-settlement mechanisms. Two other decommission proposals were overturned by verification and downgraded:

## Improve themes (63 patterns)

The recurring causes, in order of frequency:

1. **Stale references (43 patterns flagged stale):** content predates late-2025 and 2026 practice and misses current sources. Examples: `action-selector-pattern` (missing CaMeL and OWASP guidance from the same research group), `agent-modes-by-model-personality` (Amp's Season 2 pivot).
2. **Single-source, self-reported evidence:** the only reference is the author's own repo or blog. Examples: `board-mediated-inter-agent-coordination` (all claims verify, but only against the author's blueprint), `markdown-polis-coordination` (5-star repo, plus `related:` links to patterns that do not exist in the catalogue).
3. **Thin "Evidence" sections:** grades set to `medium` or `high` with nothing behind them.
4. **Broken or stale identity:** moved repos, renamed accounts (`markdown-polis-coordination` moved from `yehudalevy-collab` to `ymxlx`).
